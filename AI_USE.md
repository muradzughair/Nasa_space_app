# AI use statement

Analog Atlas was built with the help of generative AI. This file states what
was AI-generated and how the team checked it.

## What was generated with AI

The team used Anthropic's Claude models (Claude Opus 5.5, Claude Sonnet 5.5
and Claude Fable 5.2) as coding assistants. They wrote or co-wrote:

- **Code:** the web app (React, TypeScript, CesiumJS), the rover simulator
  port, the scoring and heatmap code, and the styles.
- **Data processing:** the scripts in `scripts/` that download public
  datasets and build the global grid, the lunar grid and the analog-site
  data in `public/data/`.
- **Checks:** the automated checks in `scripts/rover-check/`.
- **Documentation:** the README, this file and the notes in `docs/`.

Commits made with an AI assistant are marked in the git history with a
`Co-Authored-By: Claude …` line.

## What was not generated by AI

- **The data values.** Every measurement comes from the public datasets
  listed in the README ("Datasets"), such as NASA MODIS, Copernicus DEM and
  USGS Astrogeology. The AI wrote the code that downloads and processes
  them; it did not invent values.
- **The scores.** The app computes every score with a fixed formula
  (`src/analog/scoring.ts`). No language model runs inside the app, and no
  score, ranking or text on screen is produced by AI at run time.

## Human verification

The team reviewed all of the AI-generated code, data-processing scripts and
documentation before including it in the project. The team also ran the app
and the automated checks (`npm run build` and the checks in
`scripts/rover-check/`). The team is responsible for the final content.
